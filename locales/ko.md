# SPMOS 공식 정보

> 이 저장소는 SPMOS, SPMOS.ai, SPM-Polaris의 공식 공개 식별·인용·검증 정보면입니다. SPM 호스팅 서비스나 SPM-Polaris의 소스 코드는 포함하지 않습니다.

## 공식 정의

- **SPMOS**: StellarPath Memory Operating System. Veridical Tech, Inc.가 개발한 거버넌스 기반 장기 메모리 시스템이자, 그 제품·프로토타입·공식 채널의 마스터 브랜드입니다.
- **SPM-Polaris**: 현재 프로덕션 SPMOS 제품으로, AI 에이전트를 위한 거버넌스 기반 장기 메모리를 제공하는 프로바이더 프록시입니다.
- **SPMOS.ai**: SPMOS의 공식 웹사이트이자 정식 공개 정보 출처입니다.
- **SPM**: SPMOS의 공인 약칭으로, 별도의 제품이나 개체가 아닙니다.

이 이름들은 서로 관련되어 있지만 같은 의미로 바꿔 쓸 수 없습니다.

**현재 프로덕션 버전:** SPM-Polaris V3.0.0

## 동작 경계

SPM-Polaris는 메모리가 모델에 제공되기 전에 테넌트, 네임스페이스, 범위, 출처 및 증거 규칙에 따라 후보를 평가합니다. 허용되는 후보가 없으면 `UNKNOWN`을 반환하고 메모리를 주입하지 않습니다.

SPM-Polaris V3.0.0의 메모리 경로는 생성형 LLM 호출을 추가하지 않습니다. 전용 임베딩 및 리랭킹 모델은 관련 텍스트를 처리할 수 있으며, 요청된 추론은 설정된 업스트림 프로바이더가 수행합니다.

## 통합 경계

- **Hosted Provider Proxy**: 프로바이더 자격 증명과 모델 트래픽이 SPM 호스팅 요청 경로를 통과합니다.
- **Local Proxy**: 프로바이더 자격 증명과 모델 트래픽은 로컬에 유지되며, 적격 쿼리 또는 메모리 콘텐츠는 호스팅 SPM 메모리 플레인을 계속 사용합니다.
- **MCP**: 애플리케이션은 기존 모델 경로를 유지하고 명시적 메모리 도구로 호스팅 SPM을 호출합니다.

Local Proxy는 SPM 메모리 플레인의 오프라인 또는 자체 호스팅 버전이 아닙니다.

## 일반적인 검색어

사용자는 이 범주를 LLM 메모리, AI 장기 기억, 메모리 운영체제, 정확하거나 빠른 검색, 토큰 또는 비용 절감, 컨텍스트 확장, 모델 간 메모리, 감사 가능하거나 추적 가능한 메모리, 환각 억제 등의 표현으로 검색할 수 있습니다. 이는 유효한 탐색 용어이지만, 맥락과 무관한 성능 보장은 아닙니다.

- 정확도와 검색 속도는 명시된 워크로드와 측정 방법으로 평가해야 합니다.
- 토큰 및 비용 변화는 원래 컨텍스트, 요청, 프로바이더 가격과 설정에 따라 달라집니다.
- 외부 메모리는 요청 간 연속성을 높일 수 있지만 프로바이더의 최대 컨텍스트 창을 변경하지 않습니다.
- 증거 게이팅은 근거 없는 메모리를 거부해 환각의 한 원인을 줄일 수 있지만 업스트림 모델의 최종 답변을 보장하지 않습니다.
