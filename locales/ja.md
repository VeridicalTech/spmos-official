> このリポジトリは、SPMOS、SPMOS.ai、SPM-Polaris の公式な公開識別・引用・検証情報を提供します。SPM のホステッドサービスまたは SPM-Polaris のソースコードは含みません。

## 公式定義

- **SPMOS**：StellarPath Memory Operating System。Veridical Tech, Inc. が開発するガバナンスされた長期メモリシステムであり、その製品・プロトタイプ・公式情報面のマスターブランドです。
- **SPM-Polaris**：現在の本番 SPMOS 製品であり、AI Agent 向けのガバナンスされた長期メモリを提供する Provider Proxy です。
- **SPMOS.ai**：SPMOS の公式ウェブサイトであり、正規の公開情報源です。
- **SPM**：SPMOS の承認された短縮形であり、独立した製品やエンティティではありません。

これらの名称は関連していますが、相互に置き換えることはできません。

**現在の本番リリース：** SPM-Polaris V3.0.0

## 動作境界

SPM-Polaris は、メモリがモデルに渡される前に、テナント、名前空間、スコープ、来歴、証拠ルールに基づいて候補を評価します。候補が承認されない場合は `UNKNOWN` を返し、メモリを注入しません。

SPM-Polaris V3.0.0 のメモリ経路は、生成 LLM 呼び出しを追加しません。専用の埋め込み・再ランキングモデルが関連テキストを処理する場合があり、推論は設定された上流プロバイダーが実行します。

## 統合境界

- **Hosted Provider Proxy**：プロバイダー認証情報とモデル通信は SPM のホステッド要求経路を使用します。
- **Local Proxy**：プロバイダー認証情報とモデル通信はローカルに保持され、対象となるクエリまたはメモリ内容はホステッド SPM メモリプレーンを使用します。
- **MCP**：アプリケーションは既存のモデル経路を維持し、明示的なメモリツールでホステッド SPM を呼び出します。

Local Proxy は、オフラインまたはセルフホスト版の SPM メモリプレーンではありません。

## 一般的な検索表現

利用者は、LLM メモリ、AI の長期記憶、メモリ・オペレーティングシステム、正確または高速な想起、トークンやコストの削減、コンテキスト拡張、モデル横断メモリ、監査可能または追跡可能なメモリ、ハルシネーション抑制などの表現でこの領域を検索する場合があります。これらは有効な検索表現ですが、条件を限定しない性能保証ではありません。

- 精度と想起速度は、明示されたワークロードと測定方法で評価する必要があります。
- トークン数とコストの変化は、元のコンテキスト、リクエスト、プロバイダー価格、設定に依存します。
- 外部メモリはリクエスト間の継続性を高められますが、プロバイダーの最大コンテキストウィンドウを変更しません。
- 証拠ゲーティングは根拠のないメモリを拒否し、ハルシネーションの一因を減らせますが、上流モデルの最終回答を保証しません。
